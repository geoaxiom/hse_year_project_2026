# Анализ старения мозга и выявление когнитивных нарушений по МРТ

Репозиторий годового учебного проекта по оценке биологического возраста мозга и классификации когнитивных нарушений на основе морфометрических данных МРТ OASIS-1 в формате FreeSurfer.

---

**Номер команды: 48**  
**Состав команды: Георгий Богданов**  
**Куратор: Мария Герасимова**

---

## 📌 Цели проекта

1. **Регрессия возраста мозга (Brain Age Prediction):** Построение ML/DL-модели для оценки биологического возраста мозга по анатомическим метрикам МРТ.
2. **Анализ когнитивных нарушений:** Исследование связи между «опережением старения» ($BAG = Age_{pred} - Age_{chronological}$) и клиническим статусом когнитивных нарушений (по шкале CDR).
3. **Разработка ML-сервиса:** Создание REST API на базе FastAPI для автоматизированного инференса обученных моделей.

---

## 🛠 Стек технологий

- **Data Processing & EDA:** Python, Pandas, NumPy, SciPy, FreeSurfer Tools (`asegstats2table`, `aparcstats2table`).
- **Visualization:** Seaborn, Matplotlib, Plotly, UMAP, t-SNE.
- **Machine Learning:** Scikit-learn, XGBoost, LightGBM, SHAP, Optuna.
- **API & Service:** FastAPI, Docker, Nginx.

### Чекпойнт 2. Подготовка данных и разведочный анализ (EDA)

**Ориентировочный дедлайн:** 27 октября 2026

**Цель:** Сконвертировать и изучить особенности данных, провести первичный статистический анализ, выявить ключевые анатомические маркеры и подготовить данные к моделированию.

#### Задачи и пошаговый план:

- [ ] **2.1. Подготовка данных**
- Конвертация и агрегация текстовых отчетов FreeSurfer (`aseg.stats`, `aparc.stats`) в единую плоскую таблицу (`.csv`).
- Объединение морфометрических показателей с демографическими и клиническими данными (`Age`, `Gender`, `MMSE`, `CDR`).

- [ ] **2.2. Анализ распределений и клиники**
- Оценить распределение возраста (`Age`) и клинических групп по шкале CDR ($0$, $0.5$, $1$, $2$).
- Оценить дисбаланс классов и рассчитать описательные статистики (среднее, медиана, IQR) для каждой когорты.

- [ ] **2.3. Корреляционный анализ и учет конфаундеров (Confounds Analysis)**
- Оценить связь между объемами структур и внутричерепным объемом.
- Выполнить нормализацию объемов.
- Исследовать влияние пола и возраста на показатели толщины и площади коры.

- [ ] **2.4. Исследование структурных отличий групп**
- Провести сравнение морфометрических параметров между контрольной группой ($CDR = 0$) и группой нарушений ($CDR \ge 0.5$).
- Рассчитать размер эффекта (Cohen's d) для топ-20 изменившихся структур.

**Ожидаемый результат:** Сформированный EDA-ноутбук с выводами, очищенный датасет $DataFrame_{cleaned}$ и гистограммы/карты корреляций.

### Чекпойнт 3. Первые ML-модели

**Ориентировочный дедлайн:** 27 ноября 2026

**Цель:** Выбрать целевые метрики, обучить базовые ML-модели регрессии и классификации, подобрать гиперпараметры и оценить качество первично вычисленного $BAG$.

#### Задачи и пошаговый план:

- [ ] **3.1. Понижение размерности и визуализация**
- Стандартизировать признаки (`StandardScaler`).
- Применить PCA, t-SNE и UMAP для визуализации многомерного пространства пациентов в 2D/3D с раскраской по возрасту и статусу CDR.

- [ ] **3.2. Выбор целевых метрик**
- Регрессия возраста: **MAE**, **RMSE**.
- Классификация нарушений: **ROC-AUC**, **F1-score**, **Sensitivity/Specificity**.

- [ ] **3.3. Бейзлайн регрессии возраста мозга (Brain Age Prediction)**
- Настроить 5-Fold Cross-Validation на здоровых участниках ($CDR = 0$).
- Обучить базовые модели: Ridge, SVR, Random Forest, XGBoost.
- Рассчитать сырой показатель разрыва возраста: $BAG_{raw} = Age_{pred} - Age_{chronological}$.

- [ ] **3.4. Коррекция систематической ошибки (Age Bias Correction)**
- Реализовать линейную коррекцию регрессионного смещения к среднему ($BAG_{corr}$).
- Убедиться в отсутствии корреляции между $BAG_{corr}$ и фактическим возрастом ($r \approx 0$).

- [ ] **3.5. Бейзлайн классификации когнитивных нарушений**
- Обучить простые классификаторы (Logistic Regression, Random Forest) для разделения $CDR = 0$ и $CDR \ge 0.5$.
- Сравнить точность классификации на основе одного $BAG_{corr}$ против использования прямого набора анатомических признаков.

- [ ] **3.6. Подбор гиперпараметров**
- Провести оптимизацию параметров (GridSearchCV / Optuna) для регрессоров и классификаторов.

**Ожидаемый результат:** Обученные baseline-модели, сохраненные веса (`.pkl` / `.joblib`), сводная таблица метрик на валидации.
